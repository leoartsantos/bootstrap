#### Nome do projeto ####
FESTA & ALEGRIA

#### Descrição do projeto ###
Festa & alegria e um projeto de um web site de festa onde
com alguns cliques vocês compra e organiza sua festa em sua casa 

#### Objetivo ####
facilitar a organização de sua festa com mais conforto e praticidade 
com fotos e contato com os produtos trazendo praticidade entre cliente e empresa

### Publico Alvo #### 
Para todos que desejam fazer sua festa com mais praticidade e conforto

#### Tecnologias utilizadas ####

: HTML5 = utilizado para criar a estrutura 
: CSS3 = Para da estilo no website
: JAVASCRIPT = Dano ordens para o site sua lógica de programaçTRAPao
: BOOTSTRAP = utilizado para da menu , botoes e melhorando a responsividade

#### Estrutura do site ####

: HEADER = apresenta o nome da loja de festa
: MENU = Dano direção e permitindo navegar pelo site
: BANNER = apresenta uma imagem principal e uma mensagem em destaque
: PRODUTOS =  Apresenta algusn dos serviços com baloies e lembranças
: CONTATO = Apresenta informaçoes entre cliente e empresa
: RODAPE = Apresenta informações finais do site

O projeto utiliza recursos do Bootstrap para adaptar 
o conteúdo para todas as telas

> títulos seguem uma ordem organizada

#### Decisões de UX #####

> manter o menu no topo da tela

> evitar excesso de informações na tela
